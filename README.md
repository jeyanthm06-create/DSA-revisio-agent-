# DSA Revision Agent

## Problem
I solve LeetCode problems daily but tracking topic, pattern, complexity, 
and revision dates is manual and inconsistent. Problems get forgotten. 
Weak areas don't get identified systematically.

## Solution
An AI-powered agent that automatically analyzes every solution I push 
to GitHub, classifies it by topic and pattern, and schedules revisions 
so nothing gets forgotten.
